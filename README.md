# BobcatProxy - альтернативный клиент на базе xray 
  
**Используемые порты:** `SOCKS5` - 127.0.0.1:25443 
  

**Поддержка:**
+ VLESS вт.ч с транспортами xHTTP ( на него т.е vless основной упор ), Trojan , Hysteria2 , Shadowsocks ( на него наименьший упор так как данный протокол легко палится DPI системами)
+ Сабки с vless:// ссылками
+ JSON сабки ( в тестовом режиме )
+ Смена user-agent ( в дальнейшем будет развиваться для маскировки клиента для особо наглых VPN сервисов которые локают сервис на клиенте Happ)

  
**История:** Изначально BobcatProxy был простым клиентом вдохновленным https://github.com/AKotov-dev/XRayGUI . Часть интерфейса была вдохновлена Happ ( который перестал нынче обновлять xray-core ) . В основном проблему с апдейтом xray-core он и решает .

**Курс развития проекта:** Далее планируется добавление своего аналога crypt5 ( но работающего по другому , тупо шифрующего конфиг прямо из клиента паролем который задается пользователем самостоятельно. Что позволит передавать конфиги в подконтрольных государству платформах без риска компрометации сервера\сабки ) . 

**Изменения пре-релизов** 
 2.7 pre1: Добавлена поддержка проверки работоспособности серверов посредством GET запроса через прокси. Позволяет выявить какие сервера работают , а какие нет.
